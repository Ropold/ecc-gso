# Report Anpassung 
- Nach Update vom System des Kunden von BC21 auf BC28 ließ sich ein Report nicht mehr öffnen mit der Fehlermeldung: "Please install the ForNAV DLL version 7.0.0.2371 in your service tier Add-ins folder"
- Die ForNAV DLL Version 7.0.0.2371 wurde im Service Tier Add-ins Ordner kopiert und trotzdem lief der Report nicht.
- Lösung war, dass man den originalen Report aus BC21 noch einnmal durch den ForNavConverter laufen lassen musste, damit er kompatibel "BC Cloud & OnPrem Unversal Code (AL-extension)" wird. Die ForNAV Version 7.0.0.2371 ist mit BC28 nicht kompatibel.
